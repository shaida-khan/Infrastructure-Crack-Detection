# 🏗️ Infrastructure Crack Detection System

AI-powered infrastructure crack detection application using PyTorch, Computer Vision, and Gradio.

---

## 📌 Project Overview

This project uses deep learning and computer vision techniques to detect cracks in infrastructure images.

The system classifies uploaded images into:
- Crack
- No Crack

Designed as a practical AI application for future infrastructure inspection and monitoring workflows.

---

## 🚀 Features

- Crack vs No-Crack image classification
- PyTorch deep learning model
- Interactive Gradio web interface
- Real-time prediction results
- Computer vision workflow for infrastructure inspection
- Local deployment support

---

## 🛠️ Tech Stack

- Python
- PyTorch
- Gradio
- Computer Vision
- Jupyter Notebook

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/shaida-khan/Infrastructure-Crack-Detection.git
```

Go to the project folder:

```bash
cd Infrastructure-Crack-Detection
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
